Student Information Management System

Project Overview
----------------
This project was developed as a key component of our Java internship at the ICT Academy of Kerala. 
The primary objective was to create a robust and user-friendly application to streamline the management of student and course data for educational institutions. 
It serves as a practical demonstration of applying core software development principles in a professional setting.

Key Features
------------
The system provides a comprehensive set of functionalities for managing student records:

CRUD Operations: Users can easily Create, Read, Update, and Delete student and course records.
Advanced Search: The application supports searching for student information by ID and name.
Data Export: A feature to export all student records, including their course enrollments, to a text file for reporting purposes.
Enrollment Management: Functionality to enroll students in courses and update their performance details (marks and grades).

How to Set Up and Run the Project
---------------------------------
Database Setup:

Create a new MySQL database named studentdb.
Execute the SQL schema to create the necessary tables.

Configure Database Connection:
Open the DBConnection.java file and update the database credentials (username and password) to match your local MySQL setup.

Run the Application:
Open the project in an IDE like Eclipse.
Run the Main.java class located in com.ictkerala.app.
